# VDS Yönetim Paneli

Python ile geliştirilmiş, modüler yapıda ve JSON tabanlı veri kalıcılığı sağlayan konsol tabanlı VDS yönetim uygulaması.

## Özellikler
- **Modüler Mimari:** Mantıksal işlemler (`kutuphane.py`) ve kullanıcı arayüzü (`main.py`) ayrılmıştır.
- **Kalıcı Veri Yönetimi:** Sunucu kayıtları `sunucular.json` dosyası üzerinde saklanır.
- **CRUD İşlemleri:** Sunucu ekleme, listeleme ve silme fonksiyonları içerir.

## Çalıştırma
```bash
python main.py
